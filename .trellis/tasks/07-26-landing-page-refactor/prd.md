# 窄栏个人首页重构 PRD

## 背景

当前 Landing 已完成一轮浅色化重构，但信息结构仍是作者 Hero、写作主题、最近文章与延伸入口。新的目标是将其收敛为更像个人主页的窄栏阅读页，以根目录 `DESIGN.md` 为视觉权威，只参考 `https://ursb.me/` 的信息组织与排版节奏，不复制深色终端风格。

## 目标

- 用一条窄而舒适的内容列，在首次进入时快速说明站点状态、作者身份与最新内容。
- 页面顺序固定为：站点 Meta → 个人简介与社交入口 → 最新文章 → Slogan。
- 所有个人文案、城市与社交链接都可在管理后台修改，无需重新构建前端。
- 复用现有 Umami 与建站日期能力，不引入第二套访问统计或运行时间口径。

## Requirements

### R1 — 信息结构

页面从上到下依次展示：

1. 站点 Meta：作者所在城市的天气与温度、Umami 当前在线人数、站点运行时间；
2. 一句话个人简介，以及个人主页、Bilibili、GitHub 图标链接；
3. 最近 3 篇已发布文章；
4. 一句话 Slogan。

缺失或暂时不可用的数据应隐藏单项，不得阻塞其余内容。

### R2 — 后台配置

继续使用 `SYSTEM_BASE_CONFIG`，新增可选字段：

- `landingBio`：首页一句话简介；
- `landingSlogan`：首页底部 Slogan；
- `weatherCity`：天气查询城市；
- `personalHomepageUrl`：个人主页链接，默认 `/about.html`；
- `bilibiliUrl`：Bilibili 链接；
- `githubUrl`：GitHub 链接。

旧配置缺少字段时不得报错：简介、Slogan、个人主页和 GitHub 沿用改造前的稳定默认内容，Bilibili 与天气保持隐藏；管理员显式保存空字符串后，对应内容自动隐藏。

### R3 — 天气

- 后台只配置城市名称。
- 服务端根据城市查询实时天气与摄氏温度，短时缓存，避免每次页面访问都请求第三方服务。
- 天气服务未配置城市、城市无法解析或第三方请求失败时，公开接口返回不可用状态，Landing 隐藏天气项。
- 前端不直接请求第三方天气服务。

### R4 — 当前在线人数

- 复用现有 Umami 配置、登录与 token 缓存。
- 服务端通过 Umami active visitors 能力获取当前在线人数，并提供不含凭证的公开只读接口。
- Umami 未配置、不可用或响应异常时，Landing 隐藏在线人数，不影响页面其余区域。
- 不新增 heartbeat、presence 表或浏览器本地在线统计。

### R5 — 运行时间

- 复用 `siteFoundedDate` 与现有 `site-uptime` 工具，保持与页脚完全一致的起算口径。
- Landing 可采用更紧凑的展示文案，但不得使用第二套时间计算。
- 未配置或日期非法时隐藏运行时间。

### R6 — 最近文章

- 自动读取最近 3 篇公开文章，按现有接口排序。
- 采用窄栏文章列表或轻量卡片，不做等权重卡片墙。
- 展示日期、标题与可用时的摘要；文章区域保留 `/posts` 入口。
- 加载、空数据或请求失败不阻塞 Meta 与个人简介。

### R7 — 视觉与交互

- 以 `DESIGN.md` 的 Frost、白色、Carbon、Ash、Link Blue 与 SF Pro/system sans 为准。
- 主列宽度约 680–760px；中文正文约 17px，保持舒适行高。
- 通过留白、字号和非常轻的表面变化建立层级，减少边框，不使用卡片阴影。
- 社交入口使用项目现有 Lucide 图标体系；链接具备可见焦点、外链安全属性与至少 44px 触控目标。
- 390px、768px、1440px 均不得横向溢出；减少动态效果偏好下关闭非必要位移动效。
- 不加入“技术实践”、技能指标、虚构天气或虚构在线人数。

## Acceptance Criteria

- [ ] AC1：页面顺序严格为 Meta → 简介/社交 → 最近文章 → Slogan。
- [ ] AC2：管理员可配置简介、Slogan、城市和三个社交链接，保存后刷新公开页即时生效。
- [ ] AC3：个人主页默认 `/about.html`；任一链接为空时对应图标不渲染。
- [ ] AC4：天气由服务端按配置城市查询；失败或未配置时静默隐藏。
- [ ] AC5：在线人数来自现有 Umami active 数据链路；失败或未配置时静默隐藏。
- [ ] AC6：运行时间复用 `siteFoundedDate` 与现有计算工具，和页脚口径一致。
- [ ] AC7：最近 3 篇文章可阅读，加载/空/失败时仍可进入 `/posts`。
- [ ] AC8：页面保持浅色 Apple 风格与窄栏排版，主要层级不依赖边框或阴影。
- [ ] AC9：390px、768px、1440px 无溢出，键盘焦点、外链语义和触控尺寸有效。
- [ ] AC10：旧系统配置缺少新增字段时，后台与 Landing 均正常降级。

## Out of Scope

- 自建实时在线 presence/heartbeat 系统。
- 天气 API Key 管理、多天气供应商切换或天气预报。
- 人工精选文章、文章排序配置或 Landing 专属 CMS。
- Header、Footer、文章列表页和 About 页的视觉重构。
