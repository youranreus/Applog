# 展示访客鼠标位置

## Goal

让同一公开页面上的访客能以低频刷新的方式看到其他访客最近的鼠标位置，增加轻量的“共同在场”感，同时不干扰沉浸阅读。

## Background

- 前端为 Vue 单页应用，可从全局应用层感知路由并挂载透明展示层。
- 后端为 NestJS 应用，现有公开接口可在不需要管理员角色的情况下调用。
- 访客位置是秒级、短期的在场状态，不是分析记录，不需要长期持久化。

## Requirements

### R1 会话身份

- 每个浏览器标签页会话生成独立的内部访客键、随机四位 ID 和随机颜色。
- ID 为四位大写十六进制字符，展示格式如 `#7A3F`。
- 随机颜色从一组克制、可辨识的色板中抽取，不随每次刷新改变。
- 身份使用 `sessionStorage` 保持；关闭标签页后不再保留，不建立长期追踪。

### R2 页面与位置

- 只同步与展示同一 URL pathname 的其他访客，不同路径之间相互隔离。
- 鼠标位置以 `[0, 1]` 范围内的相对文档坐标上报和还原，以适配不同页面与屏幕尺寸。
- 未发生鼠标或触摸板移动前，不上报伪造位置。
- 当前访客不展示自己的远程鼠标标记。

### R3 启用范围

- 功能只在 Landing、文章列表、文章详情和独立页面启用。
- `/user/*`、登录/回调页与错误页不采集、不上报、不展示访客鼠标。
- 触屏设备本期不模拟鼠标位置。

### R4 同步与过期

- 客户端每 5 秒合并执行一次当前位置上报与同页访客拉取。
- 访客连续 15 秒没有更新时视为过期，不再返回或展示。
- 进入新的公开页面或标签页恢复可见时立即同步；标签页处于后台时暂停采集与轮询。
- 同一页面最多返回并展示最近活跃的 20 个其他访客。
- 同步失败不影响主页面使用，不向读者展示全局错误提示。

### R5 展示

- 每个其他访客显示为简约线性鼠标图标和 `#xxxx` 标签，图标与标签使用该访客颜色。
- 展示层覆盖页面文档但必须 `pointer-events: none`，不阻断点击、选择、滚动或键盘操作。
- 位置更新可使用短暂、克制的位移过渡；在 `prefers-reduced-motion: reduce` 下禁用过渡。
- 图标和标签不使用阴影或卡片容器，避免破坏站点的平面、安静风格。

## Acceptance Criteria

- [x] AC1：两个访客打开同一公开路径并移动鼠标后，能在下一个 5 秒刷新周期看到对方最近的鼠标位置。
- [x] AC2：不同 pathname 的访客不会相互显示，当前访客也不会看到自己。
- [x] AC3：远程鼠标以随机颜色的简约图标和四位十六进制 ID 显示，不阻断页面交互。
- [x] AC4：同一标签页会话内的内部访客键、ID 和颜色保持稳定；关闭后重新打开会生成新身份。
- [x] AC5：连续 15 秒未更新的访客不再返回，每次最多返回 20 个其他访客。
- [x] AC6：前台标签页每 5 秒最多发起一次同步请求；后台标签页和非启用路由不轮询。
- [x] AC7：对于不同视口尺寸和滚动位置，远程鼠标保持大致相同的相对文档位置。
- [x] AC8：访客同步接口具有输入校验，并通过后端单元测试、前后端类型检查与构建。

## Out of Scope

- WebSocket/SSE 实时同步、鼠标轨迹回放或点击行为记录。
- 跨设备或跨标签页的持久访客身份。
- 后台页面、登录/回调页、错误页与触屏手势的鼠标展示。
- 记录鼠标轨迹或复原不同响应式布局中的像素级位置。
