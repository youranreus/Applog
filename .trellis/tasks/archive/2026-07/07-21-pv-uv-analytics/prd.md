# PRD: 博客 PV/UV 统计与后台展示

## Background

博客需要可感知的流量数据。现状：

- 文章/页面实体有终身累计 `viewCount`，在公开详情 GET 时自增，前台展示「N 次浏览」
- `/user/dashboard` 侧栏仅有「个人统计 / 系统设置」；个人统计只有文章/页面/评论数量，无 PV/UV、无时间序列
- 无独立 analytics 模块、无 visitor 去重、无图表库

经 grilling 确认：在保留 `viewCount` 的前提下，新增带时间维度的站点级 + 内容级 PV/UV，并在概览页展示。

## Goal

让管理员在 `/user/dashboard` 一眼看到站点今日与近 7 日流量，并能切到「流量详情」查看近 30 天趋势与内容 Top 榜；公开读者不受影响，现有「N 次浏览」继续可用。

## Confirmed Decisions

| 决策点 | 结论 |
|--------|------|
| 范围 | 站点级 + 内容级；概览摘要 + 详情 tab |
| `viewCount` | **保留**，与新统计并存；不回溯、不对齐历史 |
| 计费对象 | 仅已发布文章/页面详情；列表/Landing/basic 不计 |
| 采集 | 前端详情加载成功后 `POST` 独立上报；`viewCount++` 仍走原 GET |
| UV 标识 | `localStorage` 中长期 UUID（`applog_vid`） |
| 去抖 | 同 visitor + 同内容 **30 分钟**内只记 1 次有效 PV |
| 排除自己 | 已登录且为该内容作者 → PV/UV 都不计 |
| 存储 | 日聚合为主 + 日去重表；去重行约 90 天；聚合长期保留 |
| 切日时区 | 固定 `Asia/Shanghai` |
| 爬虫/限流 | 信任前端上报路径；不做 UA 黑名单、不做 IP 限流 |
| 查看权限 | **仅管理员**；非管理员不展示摘要与流量 tab |
| 聚合范围 | 全站已发布内容 |
| UI | 个人统计加 4 个摘要数字；侧栏新 tab「流量详情」；SVG 趋势，无图表库 |
| Top 榜 | 近 30 天按 **PV** 降序，旁注 UV；文章/页面各 Top 10 |
| 不做（MVP） | 自定义日期、单篇下钻、Cookie 横幅、历史回填 |

## Requirements

### R1 — 访问上报

- 公开文章详情、页面详情在内容加载成功后上报一次浏览事件
- 请求体包含：`visitorId`、内容类型（post/page）、内容标识（建议稳定 id）
- 服务端校验：目标必须为已发布内容；`visitorId` 须为合法 UUID
- 作者本人（已登录且为该内容 author）直接忽略，不计 PV/UV
- 30 分钟去抖：窗口内重复上报不增加 PV（UV 按日去重表处理）

### R2 — 日聚合存储

- 按上海日历日维护站点级与内容级日聚合（PV、UV）
- 日去重表支持「今日该 visitor 在某 scope 是否已计 UV」
- 另存短时上次命中信息以支持 30 分钟去抖
- 去重辅助数据可定期清理（约 90 天）；聚合表长期保留
- 数据从上线日起累计，不迁移历史 `viewCount`

### R3 — 概览摘要（个人统计 tab）

管理员可见，在现有创作统计旁或下方增加（延续统计行气质，非彩虹卡片墙）：

- 今日 PV、今日 UV
- 近 7 日 PV、近 7 日 UV

非管理员：不渲染这些行。

### R4 — 流量详情 tab

- 管理员侧栏新增「流量详情」（或等价文案）
- 近 30 天按日 PV/UV 趋势（简单 SVG 折线/双系列，克制）
- 文章 Top 10、页面 Top 10（近 30 天 PV 降序，展示 UV）
- 非管理员：不渲染该 tab

### R5 — 查询 API（管理员）

提供只读接口供前端拉取：

- 摘要：今日 + 近 7 日站点 PV/UV
- 趋势：近 30 天站点日序列
- 内容榜：近 30 天 post/page Top 10（含标题等展示字段）

## Out of Scope

- 替换或回写实体 `viewCount`
- 首页/列表/搜索等入口页流量
- 自定义日期范围、单篇趋势下钻
- 引入 chart.js / echarts 等图表库
- Cookie 同意横幅、IP 入库、UA 黑名单、IP 限流
- 多时区配置、分钟级实时曲线
- 非管理员查看流量

## Acceptance Criteria

- [ ] 匿名访客打开已发布文章/页面详情后，管理员可在当日摘要中看到 PV（及首次时的 UV）增长
- [ ] 同一 visitor 30 分钟内重复打开同一内容，PV 不重复增加
- [ ] 作者登录后打开自己的已发布详情，PV/UV 不增加
- [ ] 未发布内容无法通过上报计入统计
- [ ] 管理员在「个人统计」看到今日与近 7 日 PV/UV
- [ ] 管理员可切到「流量详情」看到近 30 天趋势与文章/页面 Top 10
- [ ] 非管理员看不到 PV/UV 摘要与流量 tab
- [ ] 公开页「N 次浏览」（`viewCount`）行为与现网一致，未被本功能破坏
- [ ] 趋势可视化未引入新的图表依赖

## Packages

- `@applog/backend` — analytics 模块、实体、上报与查询 API
- `@applog/frontend` — visitorId、详情上报、Dashboard 摘要与流量 tab
- `@applog/common`（可选）— 共享 DTO / 常量，若跨包需要
