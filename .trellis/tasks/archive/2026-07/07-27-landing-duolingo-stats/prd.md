# Landing 多邻国学习统计

## Goal

在公开 Landing 页面增加一段克制、易读的个人学习轨迹，让访客能够了解作者近期及年度的多邻国学习状态，同时确保 Duolingo 凭证不会进入浏览器、公开响应或日志。

用户价值：

- 让 Landing 在“认识作者”这一主路径中增加真实、持续更新的个人侧写。
- 用近期数据和年度节奏表达学习习惯，不把个人首页变成高密度数据仪表盘。

## Background

- 现有 Landing 由站点状态、个人介绍、最近文章和 Slogan 组成，视觉基调为安静、低密度、Apple 风格。
- DuoDash 使用 Duolingo 未公开文档化接口；公开用户名查询当前可匿名访问，但主用户数据和 XP 日汇总需要 JWT。
- Duolingo 接口不提供可依赖的浏览器 CORS，且 JWT 属于账号凭证，因此第三方请求必须发生在 Applog 服务端。
- 数据字段、认证策略和可用性可能变化；完整调研见 `research/duodash-data-sources.md`。

## Requirements

### R1. 展示范围

Landing 展示以下六类统计：

1. 当前连胜天数。
2. 当前联赛段位；不得把段位表述为联赛内名次。
3. 最近 7 个自然日（含今天）的累计经验。
4. 最近 7 个自然日（含今天）的累计学习时间。
5. 历史累计 XP 最高的两种学习语言及其占全部语言 XP 的比例。
6. 当前年度每日学习 XP 热力图。

### R2. 数据口径

- 连胜优先使用 `site_streak`，缺失时回退 `streak`。
- 联赛只接受 Duolingo tier `0..9`；未知值视为暂无可靠数据。
- 7 日经验按每日 `gainedXp` 聚合，缺失日期补 0。
- 学习时间只使用 `totalSessionTime`；缺失时不得用 XP 推算值伪装为精确学习时间。
- 语言分布排除明确的数学、音乐等非语言课程；同一 `learningLanguage` 合并 XP，以全部语言 XP 为占比分母后取前 2。
- 年度热力图补齐本年日历；未来日期、真实 0 XP 和数据缺失必须保持可区分。
- 日期字符串按日历日期键处理；Unix 时间戳才按配置的展示时区转换。

### R3. 安全与隐私

- Duolingo JWT 仅允许在服务端读取和使用。
- JWT 不得进入前端 bundle、公开 API 响应、HTML、客户端存储或日志。
- 公开接口只返回 Landing 所需的稳定聚合 DTO，不透传 Duolingo 原始用户对象。
- 管理员读取凭证配置时必须脱敏；空值或脱敏占位提交不得意外清除已有凭证。

### R4. 可用性与降级

- 服务端缓存成功结果至少 30 分钟，避免每位访客触发 Duolingo 上游请求。
- 上游超时、401/403、字段变化或暂时不可用时，优先继续返回最近一次成功快照并标记为过期。
- 没有成功快照时，Landing 其余内容仍须正常渲染；学习统计使用安静的空态或整段隐藏，不出现技术错误。
- 页面首次加载不能因 Duolingo 请求阻塞已有站点状态、个人介绍和文章内容。

### R5. Landing 体验

- 学习统计作为个人叙事的一部分，不使用后台仪表盘式彩色指标卡墙。
- 语言分布最多展示两个小卡片。
- 热力图在桌面和移动端均可读；移动端不得造成整页横向滚动。
- 所有统计状态和图形应有可访问文本，不能只靠颜色表达强度或状态。
- 尊重系统“减少动态效果”设置，不为该模块引入无必要持续动画。

### R6. 管理与启停

- 未配置或显式停用时，公开 Landing 不展示学习统计。
- 管理员通过系统设置配置 Duolingo 用户名、JWT、展示时区和启用状态。
- 配置保存在独立的 `SYSTEM_DUOLINGO_CONFIG`；JWT 与现有 Umami 密码采用相同的数据库明文存储、管理员脱敏读回模式。
- 配置保存后无需重新构建前端即可生效。

## Acceptance Criteria

- [ ] AC1：配置有效时，Landing 展示连胜、联赛段位、最近 7 天 XP、最近 7 天学习时间、前 2 语言分布和当前年度热力图。
- [ ] AC2：最近 7 天固定覆盖含今天的 7 个日期；XP 缺日补 0，学习时长缺失保持“未知”而不是伪造为 0 或估算值。
- [ ] AC3：联赛只展示段位名称；无可靠 tier 时展示空态，不出现错误数组下标或“第 N 名”文案。
- [ ] AC4：语言比例以全部有效语言 XP 为分母，页面最多渲染两种语言，并排除明确的非语言课程。
- [ ] AC5：年度热力图覆盖当前年份，未来日期、0 XP 日期与缺失数据具有不同语义；移动端无页面级横向滚动。
- [ ] AC6：浏览器网络响应、页面源代码、前端构建产物和应用日志中均不包含 Duolingo JWT。
- [ ] AC7：公开请求命中服务端缓存；多位访客在缓存有效期内不会各自触发上游请求。
- [ ] AC8：上游失败且存在成功快照时返回快照并标记过期；无快照时 Landing 其他区块不受影响。
- [ ] AC9：管理员可以读取脱敏配置、更新 JWT、启停功能；空值或脱敏占位不会误删已有 JWT。
- [ ] AC10：前后端类型检查、相关单元测试和生产构建通过。

## Out of Scope

- 展示 Duolingo 当前联赛内的具体名次或排行榜成员。
- 在 Applog 中登录 Duolingo、自动获取 JWT 或自动续期 JWT。
- 展示 Duolingo 原始个人资料、好友、成就、任务或完整课程列表。
- 长期保存每次抓取的历史快照，或建立独立的学习数据数据库。
- 在 Landing 提供年份切换、筛选、钻取或复杂交互式图表。
