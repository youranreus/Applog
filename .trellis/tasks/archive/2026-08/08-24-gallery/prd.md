# 实现相册功能

## Goal

为 Applog 增加一个基于阿里云 OSS 存储、通过 CDN 访问的公开相册，让游客和普通用户可以浏览按相册组织的照片，并让管理员能够维护相册内容及照片信息。

## Background

- 现有项目为 Vue 3 前端、NestJS/TypeORM/MySQL 后端和 `@applog/common` 共享契约的单仓库结构。
- 现有管理端已具备管理员专用配置接口、敏感字段脱敏读回、应用级 AES-256-GCM 持久化加密和公开/管理 API 分离模式；OSS 凭证应沿用这些安全边界。
- 现有前台导航由集中式导航配置生成，可根据公开相册状态动态过滤“相册”入口。
- 当前项目没有通用文件上传、OSS SDK 或 EXIF 解析依赖，需要按最终编辑范围补齐。
- 实际部署不是阿里云函数计算，技术方案不得把仓库中的 FC 配置当作生产资源约束。

## Requirements

### R1. OSS 与 CDN 配置

- 管理端提供阿里云 OSS 基础配置，至少覆盖 endpoint、access key、access secret，以及代码接入所需的 bucket 等必要字段。
- 管理端提供 CDN 域名配置，用于生成照片的公开访问 URL。
- 访问凭证不得暴露给用户端。
- 管理端提供“测试连接”；测试应验证目标相册目录的列举、临时写入和临时对象删除权限，并清理测试对象。
- endpoint、bucket、access key、access secret、CDN 域名或相册根目录发生变化后，之前的连接测试结果立即失效。

### R2. 相册功能配置

- 管理端提供相册启用开关和相册根目录配置。
- 只有必填配置完整且当前配置已通过实际连接/目录权限测试时，管理端才允许开启相册功能。
- 相册开关关闭时，用户端不展示相册入口，公开相册页面也不得继续提供相册内容。

### R3. 导航与访问权限

- 相册启用后，用户端顶部导航显示“相册”。
- 游客和普通登录用户只能浏览相册与照片。
- 不建设独立的相册管理页面；管理员在与访客相同的用户端相册页面内完成管理，避免维护两套界面。
- 管理员在相册页面可以创建相册，编辑相册标题、描述和发布时间，上传和删除照片，并编辑照片的标题、描述、发布时间及经纬度。
- 相册目录在创建后作为 OSS 路径标识，不随展示标题变化；管理员可在创建时填写安全的目录名。
- 非空相册禁止删除；管理员必须先逐张删除其中照片，才可删除相册。
- 管理员专属控件仅在管理员身份下显示，所有写接口仍必须由后端独立执行管理员鉴权。

### R4. 相册浏览

- 相册页面按不同相册组织和展示照片。
- 相册按相册发布时间从早到晚排列；相册内照片按照片发布时间从早到晚排列。
- 相册发布时间在创建时默认为当前时间，管理员可以修改。
- 照片发布时间优先使用上传时解析出的 EXIF 拍摄时间，缺失时使用上传时间，管理员可以修改。
- 相同发布时间下使用稳定的记录 ID 升序作为次级排序，保证重复请求结果一致。

### R5. 照片预览与元数据

- 点击照片后打开全屏 Dialog 预览全尺寸展示图。
- Dialog 右侧展示照片 EXIF 参数、拍摄/发布时间、地点等可用信息。
- 地点不展示或解析为城市、景点等地理名称，也不接入逆地理编码服务。
- 照片包含 EXIF GPS 坐标时，在详情侧栏使用 MapCN Vue/MapLibre 展示带位置标记的小地图；无 GPS 坐标时不展示地图区域。
- 缺失的 EXIF 或地点信息以及地图底图加载失败时应有稳定的降级展示，不阻塞照片预览。

### R6. 上传格式与边界

- 支持上传 JPG/JPEG、PNG、WebP 和 HEIC 图片。
- 单张图片最大 30 MB，单次最多上传 20 张。
- HEIC 必须生成浏览器可稳定显示的展示资源，同时保留并展示能够提取的 EXIF/GPS 信息。
- 不支持 SVG 和 GIF。

### R7. 资源 URL

- 照片公开访问路径遵循 `{cdnDomain}{galleryPath}/{folder}/{filename}`。
- 路径拼接必须规范化斜杠，并对目录和文件名进行安全编码/校验。

## Acceptance Criteria

- [ ] 管理员能够保存 OSS、CDN 和相册配置，敏感凭证不会出现在用户端接口响应中。
- [ ] “测试连接”能验证相册目标目录的列举、写入和删除权限，测试对象无论成功或失败都不会被长期遗留。
- [ ] OSS/CDN/相册目录配置发生变化后，旧连接测试结果失效，必须重新测试才能开启。
- [ ] OSS 配置缺失或无效时无法开启相册；关闭相册后用户端入口和公开数据均不可用。
- [ ] 相册关闭时直接访问公开相册路由会看到明确的不可用/未开启状态，而不是旧的相册数据。
- [ ] 相册启用后，游客和普通用户可以从顶部导航进入相册并只读浏览。
- [ ] 管理员在同一用户端相册页面拥有创建/删除相册、上传/删除照片和编辑展示元数据的能力，不新增第二套相册管理页面。
- [ ] 非空相册无法删除；相册展示标题可以修改且不会改变已创建的 OSS 目录路径。
- [ ] 页面能按相册展示照片，并按最终确认的发布时间规则稳定排序。
- [ ] 点击照片可全屏预览，并在右侧看到可用的 EXIF、时间和地点信息。
- [ ] 含 GPS 的照片详情展示一个位置小地图；不含 GPS 时地图区域隐藏，照片预览保持可用。
- [ ] 地图底图加载失败不会影响照片和其他 EXIF 信息的浏览。
- [ ] 所有照片 URL 均按 CDN 域名、相册根目录、相册目录和文件名正确生成。
- [ ] 管理员可上传 JPG/JPEG、PNG、WebP 和 HEIC；格式、单文件大小和批量数量超限时收到明确错误且不产生残留记录。
- [ ] 真实 HEIC 文件能够提取可用 EXIF/GPS、生成可由主流浏览器预览的展示图，并可与源对象一同安全删除。
- [ ] 后端、管理端和用户端的相关自动化检查与测试通过。

## Out of Scope

- 视频资源。
- 面向普通用户的上传或编辑能力。
- 图片在线裁剪、滤镜和复杂修图。
- 地理名称解析、搜索或逆地理编码。
- 相册回收站、软删除和批量级联删除。
- 照片在相册之间移动；MVP 通过删除后重新上传完成归档调整。
