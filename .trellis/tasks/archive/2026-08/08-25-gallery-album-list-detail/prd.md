# 调整相册列表与详情展示

## Goal

将公开相册从“单页展开所有相册及照片”调整为“相册列表 → 相册详情”的两层浏览结构，降低首屏信息密度与照片请求量，让读者先选择相册，再在详情页沉浸式浏览该相册的照片。

## Background

- 当前 `/gallery` 页面获取相册列表后，会并发加载每个相册的照片并逐个展开瀑布流。
- 相册摘要已有 `id`、标题、发布时间、照片数量与可空封面地址，可直接支撑相册列表卡片。
- 当前照片列表已有按宽高分配列的瀑布流、游标加载更多、全屏预览、EXIF/GPS 展示及管理员编辑能力。
- 公开相册接口不返回空相册；管理员相册接口会返回空相册及恢复状态，因此管理员需要无封面占位状态。

## Requirements

### 相册列表

- `/gallery` 只请求并展示相册摘要，不请求或展开任何相册的照片列表。
- 相册以响应式封面卡片网格展示；卡片使用 8px 圆角、固定稳定的封面比例和裁切填充，视觉语言延续现有照片 item。
- 卡片左下角叠放标题与中文格式化日期，并使用克制的底部渐变保证文字在明暗封面上均可读。
- 整张卡片可点击并可通过键盘访问，进入该相册的独立详情 URL。
- 管理员在列表页保留新建、编辑、删除空相册；空相册使用与封面卡片同尺寸的无封面占位。

### 相册详情

- 相册详情通过路由中的相册 ID 定位相册，只加载该相册的照片。
- 详情页展示相册标题、日期和可选描述，并提供返回相册列表的明确路径。
- 照片区域占满页面可用宽度，不设置现有 `80rem` 内容上限；页面边缘和列之间保留一致、响应式的间距。
- 瀑布流继续按照片宽高把照片分配给当前最短列，并随可用宽度在 1、2、3 列之间响应式变化。
- 保留游标加载更多、错误重试、照片全屏预览、EXIF/GPS 信息及键盘焦点样式。
- 管理员在详情页保留上传照片、查看上传队列、编辑照片、删除或重试删除照片。

### 共享状态

- 列表页和详情页均保留相册启用状态、加载态、请求错误态与空状态。
- 无效、不可见或不存在的相册 ID 显示可恢复的“相册不存在”状态，并提供返回相册列表的操作。
- 现有公开/管理员 API 边界保持不变，普通访客不出现任何写操作。

## Acceptance Criteria

- [ ] 访问 `/gallery` 时只看到相册卡片，不出现照片瀑布流，且不会发出逐相册照片列表请求。
- [ ] 有封面的相册卡片使用圆角裁切封面，左下角清晰显示标题和日期；管理员看到的空相册有一致尺寸的占位卡片。
- [ ] 相册列表采用移动优先响应式网格：390px 一列、768px 两列、1440px 三列，且各视口无横向溢出。
- [ ] 相册卡片在鼠标、Enter 和 Space 操作下均能打开独立的 `/gallery/:albumId` 详情 URL，并有可见焦点状态。
- [ ] 相册详情只请求并展示当前相册的照片，不加载其他相册照片。
- [ ] 照片接口成功返回后加载态必须结束并渲染照片，不得因绕过 Vue Proxy 而停留在“正在读取照片”。
- [ ] 详情瀑布流使用页面全部可用宽度，边缘和列之间有间距；桌面、平板与手机分别适配 3、2、1 列且无横向溢出。
- [ ] 页面内“相册列表”入口位于固定 Header 与安全区下方，1440px 和 390px 下真实坐标点击均返回 `/gallery`。
- [ ] 列表与详情使用一致且更舒展的顶部间距，首个内容与固定 Header 在 1440px 和 390px 下至少相隔 24px。
- [ ] 详情页保留加载更多、追加失败重试、全屏照片预览、元数据和可选地图能力。
- [ ] 管理员可在列表页管理相册，并可在详情页上传、编辑和删除照片；访客无写操作。
- [ ] 空相册、图库关闭、列表/详情加载失败和无效相册 ID 均显示清晰且可恢复的状态。
- [ ] 1440px、768px 与 390px 视口下完成布局检查，照片预览继续覆盖完整视口且键盘关闭/焦点行为正常。
- [ ] 前端契约测试、lint、类型检查和生产构建全部通过。

## Out of Scope

- 修改后端相册或照片数据模型及公开 API 签名。
- 改变 OSS/CDN 存储、上传或图片处理流程。
- 新增相册排序、搜索、筛选、封面选择或照片拖拽排序。
- 新建独立的后台相册管理页面。

## Technical Notes

- 相册详情可先复用现有相册摘要列表接口定位目标相册，不为本次拆页新增单相册接口。
- 页面继续遵循 Gallery Cross-Layer Contract、Vue 3 Composition API、Alova API 分层及现有 Apple 主题设计规范。
